Interactive Elements

In-text link

CSS selector:

a

Sample code:

<p>This is a paragraph with an <a href="#">in-text link</a> inside it.</p>

Rendered element:

This is a paragraph with an in-text link inside it.

Navigation Link

CSS selector:

.button-nav

Sample code:

<a href="#" class="button">Default Button</a>

Rendered element:

Default Button

Submit/Reset Buttons

CSS selector:

input[type="submit"], input[type="reset"]

Sample code:

<input type="submit" value="Submit">
<input type="reset" value="Reset">

Rendered element:

Text Input Field with Label

CSS selector:

input[type="text"]

Sample code:

<label for="name">Name:</label>
<input type="text" id="name" name="name">

Rendered element:

Radio Button with Label

CSS selector:

input[type="radio"]

Sample code:

<input type="radio" id="html" name="fav_language" value="HTML">
<label for="html">HTML</label>

Rendered element:

Image as a Link

CSS selector:

a img

Sample code:

<a href="#"><img src="images/sample.jpg" alt="Sample description"></a>
