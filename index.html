    • Interactive Elements

    In-text link

    CSS selector:

    a

    Sample code:

    <p>This is a paragraph with an <a href="#">in-text link</a> inside it.</p>

    Rendered element:

    This is a paragraph with an in-text link inside it.

    Navigation Link

    CSS selector:

    .button-nav

    Sample code:

    <a href="#" class="button">Default Button</a>

    Rendered element:

    Default Button

    Submit/Reset Buttons

    CSS selector:

    input[type="submit"], input[type="reset"]

    Sample code:

    <input type="submit" value="Submit">
    <input type="reset" value="Reset">

    Rendered element:

    Text Input Field with Label

    CSS selector:

    input[type="text"]

    Sample code:

    <label for="name">Name:</label>
    <input type="text" id="name" name="name">

    Rendered element:

    Radio Button with Label

    CSS selector:

    input[type="radio"]

    Sample code:

    <input type="radio" id="html" name="fav_language" value="HTML">
    <label for="html">HTML</label>

    Rendered element:

    Image as a Link

    CSS selector:

    a img

    Sample code:

    <a href="#"><img src="images/sample.jpg" alt="Sample description"></a>

    </div>

    <input id="customer-email" name="email" type="email">
    </div>
    <div>
    <label for="customer-address-state">State/Province</label>
    <input id="customer-address-state" name="address" type="adress">
    </div>
    <div>
    <label for="customer-address-postal">Post code</label>
    <input id="customer-address-postal" name="address" type="adress">
    </div>
    <fieldset>
    <legend>Payment method</legend>
    <div>
    <input id="pay-card" name="payment-method" type="radio" value="card">

    <label for="pay-google">Google Pay</label>
    </div>
    </fieldset>

    </fieldset>
    </form>

    Checkout Cart

    Checkout cart
    Item Quantity Unit price Line total
    Game 1 1 $xx.00 $xx.00
    Game2 1 $yy.00 $yy.00
    Total $xx + yy.00

    Sample code:

    <table id="cart">
    <caption>Checkout cart</caption>
    <thead>
    <tr>
    <th scope="col">Item</th>
    <th scope="col">Quantity</th>
    <th scope="col">Unit price</th>
    <th scope="col">Line total</th>
    </tr>
    </thead>
    <tbody>
    <tr>
    <th scope="row">Game 1</th>
    <td>1</td>
    <td>$xx.00</td>
    <td>$xx.00</td>
    </tr>
    <tr>
    <th scope="row">Game2</th>
    <td>1</td>
    <td>$yy.00</td>
    <td>$yy.00</td>
    </tr>
    <tr>
    <th scope="row" colspan="3">Total</th>
    <td>$xx + yy.00</td>
    </tr>
    </tbody>
    <tfoot>
    <tr>
    <td><button type="submit">Checkout!</button></td>
    </tr>
    </tfoot>
    </table>
